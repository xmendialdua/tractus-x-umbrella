### Paso 4: Configurar Realm para Cookies con HTTP (Fix Error)

**Problema:** Al intentar login en /registration/, aparece error:
```
Cookie not found. Please make sure cookies are enabled in your browser.
```

**Causa:** El realm idp1 tiene `sslRequired: "external"` por defecto, bloqueando cookies en HTTP.

**Solución:**
```bash
# Obtener token de admin de SharedIdP
KC_TOKEN=$(curl -s -X POST "http://sharedidp.51.178.94.25.nip.io/auth/realms/master/protocol/openid-connect/token" \
  -d "client_id=admin-cli" \
  -d "username=admin" \
  -d "password=$(kubectl get secret -n portal portal-sharedidp -o jsonpath='{.data.admin-password}' | base64 -d)" \
  -d "grant_type=password" | jq -r '.access_token')

# Configurar realm para permitir HTTP y cookies cross-domain
curl -s -X PUT "http://sharedidp.51.178.94.25.nip.io/auth/admin/realms/idp1" \
  -H "Authorization: Bearer $KC_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "sslRequired": "none",
    "attributes": {
      "sameSiteCookies": "none"
    }
  }'
```

**Verificación:**
```bash
curl -s -X GET "http://sharedidp.51.178.94.25.nip.io/auth/admin/realms/idp1" \
  -H "Authorization: Bearer $KC_TOKEN" | jq '{sslRequired, attributes: {sameSiteCookies: .attributes.sameSiteCookies}}'

# Resultado:
{
  "sslRequired": "none",
  "attributes": {
    "sameSiteCookies": "none"
  }
}
```

**Estado:** ✅ Configuración actualizada para permitir login con HTTP

## 🐛 Problemas Encontrados y Soluciones

### 1. Error "Cookie not found" en Login

**Síntoma:**
```
Cookie not found. Please make sure cookies are enabled in your browser.
URL: http://sharedidp.51.178.94.25.nip.io/auth/realms/idp1/login-actions/authenticate...
```

**Causa:**
- Realm idp1 tiene `sslRequired: "external"` por defecto
- Las cookies con SameSite policy no funcionan en HTTP sin configuración especial

**Solución:**
```bash
# Configurar realm para permitir HTTP
KC_TOKEN=$(curl -s -X POST "http://sharedidp.51.178.94.25.nip.io/auth/realms/master/protocol/openid-connect/token" \
  -d "client_id=admin-cli" -d "username=admin" \
  -d "password=$(kubectl get secret -n portal portal-sharedidp -o jsonpath='{.data.admin-password}' | base64 -d)" \
  -d "grant_type=password" | jq -r '.access_token')

curl -s -X PUT "http://sharedidp.51.178.94.25.nip.io/auth/admin/realms/idp1" \
  -H "Authorization: Bearer $KC_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"sslRequired": "none", "attributes": {"sameSiteCookies": "none"}}'
```

**Estado:** ✅ Resuelto

### 2. Aplicación Queda en SUBMITTED (7)
