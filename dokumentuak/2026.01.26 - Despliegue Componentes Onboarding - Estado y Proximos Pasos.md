## Problema Encontrado: Falta de Recursos

### Intento de Despliegue con `values-adopter-portal-for-onboarding.yaml`

**Archivo usado:** `charts/umbrella/values-adopter-portal-for-onboarding.yaml`

**Componentes habilitados:**
```yaml
bpdm: enabled: true
selfdescription: enabled: true
smtp4dev: enabled: true
ssi-credential-issuer: enabled: true
identity-and-trust-bundle: enabled: true
bpndiscovery: enabled: false  # Correcto - no necesario aún
discoveryfinder: enabled: false  # Correcto - no necesario aún
```

**Comando ejecutado:**
```bash
cd ~/projects/assembly/tractus-x-umbrella/charts/umbrella

helm upgrade portal . \
  --namespace portal \
  -f values-adopter-portal-for-onboarding.yaml \
  -f values-ovh-hosts-portal.yaml
```

### Resultado del Despliegue

**Pods con problemas:**
```
portal-bpdm-gate                     0/1   CrashLoopBackOff
portal-bpdm-pool                     0/1   CrashLoopBackOff
portal-bpdm-cleaning-service-dummy   0/1   Error/CrashLoopBackOff
portal-bpndiscovery                  0/1   CrashLoopBackOff
portal-bpndiscovery-postgresql-0     0/1   ImagePullBackOff
portal-discoveryfinder               0/1   CrashLoopBackOff
portal-discoveryfinder-postgresql-0  0/1   Pending
portal-issuer-postgresql-0           0/1   Pending
smtp4dev                             0/1   Pending
```

**Causa raíz:**
- El cluster de OVH no tiene recursos suficientes (CPU/Memoria) para desplegar todos los componentes simultáneamente
- Múltiples PostgreSQL databases requieren PersistentVolumes que no se pueden provisionar
- Algunos pods en `Pending` por falta de recursos
- Otros pods en `CrashLoopBackOff` esperando dependencias (databases)

### Solución Aplicada: Rollback

```bash
helm rollback portal -n portal
```

**Nota:** El rollback no eliminó los pods fallidos automáticamente. Fue necesario hacer:

```bash
helm upgrade portal . \
  -f values-adopter-portal.yaml \
  -f values-ovh-hosts-portal.yaml \
  -n portal
```

Esto volvió al estado funcional con todos los componentes de onboarding deshabilitados.
