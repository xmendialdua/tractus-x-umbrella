# Acerca de la versión de Tractus-X utilizada

**Fecha de análisis:** 2026-06-08

---

## Versión en uso

Este despliegue se basa en **Tractus-X Release 25.09** (publicada el 2025-10-01), tal como declara el propio [`README.md`](../README.md) del repositorio.

El chart umbrella principal tiene versión `3.14.5` ([`charts/umbrella/Chart.yaml`](../charts/umbrella/Chart.yaml)).

El conector despliega `tractusx-connector` **0.11.1**, que es un parche menor sobre el `0.11.0` oficial de la release 25.09 (misma generación "Saturn", 0.11.x). El propio `values-ikln-connector.yaml` lo referencia explícitamente:

```yaml
# BDRS configuration with new property names (EDC v0.11.1+)
```

## Notas

- El conector IKLN (`BPNL00000002IKLN`) y el conector MASS usan ambos `tractusx-connector 0.11.1`, desplegados a través del `dataspace-connector-bundle` (versión `1.2.1`).
- El `tractusx-connector 0.11.1` es compatible con la release 25.09 y además añade soporte correcto para los nombres de propiedades BDRS de la API (`TX_EDC_IAM_IATP_BDRS_SERVER_URL`).
- La siguiente release relevante sería **26.03** (2026-03-18), que sube el conector a `0.12.0`.
